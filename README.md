# 姪っ子のための知育アプリ（企画中）

4歳の姪っ子のための知育モバイルアプリ。プログラミング的思考（順序・パターン・試行錯誤）の下地を、遊びとして届けることを狙う。絵本「ルビィのぼうけん」の延長、小学校プログラミング教育（2020年度〜必修）への接続を意識。

## 状態

**コンセプト選定中。** 市場・発達段階・幼児UX・個人開発の実現性を調査したうえでの厳選5案は [docs/IDEAS.md](docs/IDEAS.md) を参照。

## 前提・方針

- 対象: 4歳（未就学・ひらがなは読み始め）。スマホ操作経験あり
- 既存キャラIP（アンパンマン等）は使わない — 姪っ子本人が主役になる設計
- 受け身の視聴ではなく「自分で操作して考える・作る」遊び
- 作り手（おじ/おば）は遠方在住 — 離れていても関われる要素を重視
- MVPはコア機能1つに絞る。まず姪っ子1人が喜べばOK、ストア公開は二の次
- 技術: Expo (React Native + TypeScript) 予定

## リポジトリ名について

アプリ名決定までの仮名（chiiku-app）。決定後にリネーム予定。
